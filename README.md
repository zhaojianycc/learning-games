# 小鸡救援队——乘法城堡大闯关

这是一个面向低年级学生的离线乘法口诀闯关游戏。

## 开始游戏

双击 `index.html`，推荐使用 Microsoft Edge、Google Chrome 或其他现代浏览器打开。

## 游戏规则

- 一共 10 关，每关 3 道四选一题目。
- 每关开始时有 3 颗爱心，答错会扣除 1 颗。
- 爱心用完后可以重新挑战当前关卡。
- 题目包含基础口诀、补充乘数、乘法交换、简单括号分组和比较题。
- 前 3 关提供重复加法或拆数提示，后续关卡取消提示并提高独立思考难度。
- 等值算式题会考察乘法与连加、灵活拆数之间的关系，例如 `3×3 = 3+3+3 = 2+3+4`。
- 游戏会自动在当前浏览器中保存进度。
- 第 10 关击败 Boss 后，可下载带日期、成绩统计和唯一证书编号的 PNG 徽章。
- 通关且正确率达到 90% 的成绩会参与“乘法极速榜”排名；榜单按通关用时保留历史最快 20 名。
- 刷新历史最快纪录时，通关页面和下载的证书都会显示破纪录标记。
- 榜单已连接 Supabase 云端：Windows、Android 和 iPad 打开同一网址即可共享前 20 名，不要求安装 PWA。
- 断网或云端暂时不可用时会自动使用当前设备的本地榜单，游戏仍可正常进行。

## 文件说明

- `index.html`：游戏页面
- `style.css`：界面样式与动画
- `game.js`：题目、关卡、计分、存档及徽章逻辑

游戏不需要联网，也没有外部资源依赖。若浏览器询问下载位置，请选择希望保存徽章的文件夹。

## 在安卓 PAD 上安装（PWA）

PWA 安装必须从 HTTPS 网站打开，直接双击本地 `index.html` 时只能游玩，无法启用离线安装服务。

1. 将本文件夹的全部内容上传到任意 HTTPS 静态网站空间（例如 GitHub Pages、Cloudflare Pages 或学校网站）。
2. 在安卓 PAD 上使用 Chrome 或 Edge 打开游戏网址。
3. 点击首页的“安装到桌面”；若该按钮未出现，打开浏览器菜单并选择“安装应用”或“添加到主屏幕”。
4. 安装完成后，从桌面上的“乘法闯关”图标启动。
5. 首次完整打开后，游戏文件会缓存到设备，断网也可以继续运行。

更新游戏时，将新版文件上传到同一网址。应用联网打开后会在后台更新缓存；必要时关闭并重新打开一次即可看到新版。
