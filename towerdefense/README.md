# 四域守护战 · 答题塔防

这是一个独立于原“乘法闯关游戏”的纯静态 PWA 小游戏，支持数学、英语两种模式。

## 运行

不能直接双击 `index.html` 测试离线安装，建议在当前目录启动静态服务器：

```powershell
python -m http.server 8765
```

然后访问 `http://localhost:8765/答题四域塔防/`。

## 已实现规则

- 严格回合制：每回合答一道题、行动一次、怪物行动一次。
- 10 关、4 条战线、5 点生命，不能修复或防御。
- 普通弹消耗 10 能量；连击获得钻石，可购买 4 类专用弹。
- 数学、英语使用不同题目逻辑和独立本地榜单。
- 仅通关且正确率不低于 90% 的成绩入榜，按最少回合排序，只保留前 20 名。
- 支持安装为 PWA 和离线游玩。

## 榜单说明

榜单已接入现有 Supabase 服务，数学与英语按不同前缀分榜，可在 Windows、Android 和 iPad 间共享。离线时成绩先保存在浏览器 `localStorage`，下次联网打开榜单会自动补传。
